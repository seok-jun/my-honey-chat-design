My Honey Chat UI/UX Visual Specs

이 저장소는 seok-jun/my-honey-chat의 UI/UX Visual Spec 전용 저장소다.

원칙
  • UI/UX 변경을 시각적으로 검토해야 할 때만 HTML을 만든다.
  • 비즈니스 프로세스, 데이터 흐름, provider 라우팅, 모듈 구조는 여기서 관리하지 않는다.
  • Visual Spec은 실제 앱 구현이 아니라 화면 배치·정보 계층·상태·인터랙션의 계약이다.
  • 앱 이슈의 기능 요구사항과 충돌하면 기능 동작은 앱 이슈가 우선한다.

파일 규칙

  • 앱 이슈 번호를 파일명으로 사용: issues/57.html
  • 한 이슈는 가능한 한 self-contained HTML 하나로 관리한다.
  • CSS와 최소 JavaScript는 HTML 안에 포함한다.
  • npm, bundler, framework, 외부 CSS/JS 의존성을 추가하지 않는다.
  • Current / Proposed, default / loading / empty / error 등 필요한 상태를 한 파일에서 비교 가능하게 만든다.

생성 기준

신규 화면, 주요 레이아웃 변경, navigation/modal/sheet/gallery/picker 변경, 다중 UI 상태처럼 텍스트만으로 화면 구조가 하나로 결정되지 않는 경우 Visual Spec을 만든다.

문구·색상·간격·아이콘의 단순 수정이나 기존 UI를 그대로 유지하는 버그 수정에는 만들지 않는다.
