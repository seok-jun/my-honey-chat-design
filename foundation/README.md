# some:You Foundation

> 어딘가에 있을 너와 나를 연결해 주는 **some:You**

이 폴더는 앱 전체에 공통으로 적용하는 브랜드·디자인 기준이다. 이슈별 Visual Spec(`issues/*.html`)은 이 기준 위에서 화면 배치와 상태만 다룬다.

| 파일 | 내용 |
| --- | --- |
| `tokens.json` | 색·글자·간격·모서리·크기·모션 값의 **원본** |
| `index.html` | 토큰과 핵심 컴포넌트 견본 (Pages: `/foundation/`) |
| `compose/` | Jetpack Compose 테마 코드 초안 (`Color.kt`, `Type.kt`, `Shape.kt`, `Theme.kt`) |
| `icon/source/` | 앱 아이콘 SVG 원본 (전체·배경·전경·단색) |
| `icon/export/` | Android 리소스(`res/`)와 512px 이미지 |

값을 바꿀 때는 `tokens.json`을 먼저 고치고, 이 문서의 표와 `compose/*.kt`를 같은 커밋에서 맞춘다.

`issues/*.html` 중 **2026-10-12 이전에 만든 시안은 이 기준이 생기기 전의 구 팔레트**(`#F0A8B7`, `#8E4E61`, `#B9ADB1`, `#171317`, `#2A2429` 등)를 담고 있다. 그 시안은 화면 배치와 정보 계층의 기준으로 계속 쓰고, 색·글자·치수는 이 문서와 `tokens.json`을 따른다. 기존 시안을 다시 칠하지 않는다. 완료된 시안은 당시 승인 기준의 기록이다.

## 1. 디자인 원칙

한 문장 기준: **"카톡처럼 익숙하고, 상대가 진짜 거기 있는 것처럼."**

1. **메신저 문법은 그대로** — 내 메시지 오른쪽, 상대 왼쪽+아바타, 날짜 구분선, 읽음 표시. 새로 배울 것이 없어야 한다.
2. **캐릭터가 주인공** — 아바타, 상태 문구, "입력 중", 선톡 알림이 사람처럼 보여야 한다.
3. **밤하늘 한 가지 톤** — 인디고 배경 + 별빛 포인트 하나. 그 외 색을 늘리지 않는다.
4. **화려함은 움직임에** — 본문은 조용히, 전송·수신·리액션 순간에만 모션.
5. **접근성 바닥선** — 텍스트 대비 4.5:1 이상, 터치 영역 48dp, 라이트/다크 모두 지원.

기본 테마는 **다크**다(아이콘·브랜드와 같은 밤하늘). 라이트는 시스템 설정을 따를 때 쓴다.

## 2. 컬러

Material 기본 색과 Dynamic Color(배경화면 연동)는 쓰지 않는다. 기기마다 분위기가 바뀌면 캐릭터 인상도 흔들린다.

| 토큰 | 다크 | 라이트 | 용도 |
| --- | --- | --- | --- |
| `background` | `#0E0B1F` | `#F5F3FC` | 화면·채팅방 배경 |
| `surface` | `#1E1838` | `#FFFFFF` | 캐릭터 말풍선, 카드 |
| `surfaceVariant` | `#262046` | `#ECE8F8` | 입력창, 칩, 날짜 구분선 |
| `outline` | `#3A3260` | `#DCD5F2` | 말풍선·카드 1dp 테두리 |
| `onSurface` | `#ECE8FF` | `#1C1733` | 본문 |
| `onSurfaceVariant` | `#A9A2C9` | `#5F5880` | 시간, 읽음, 보조 글자 |
| `primary` | `#9C8FFF` | `#4F3FC4` | 전송 버튼, 링크, 선택 상태 |
| `onPrimary` | `#120E2A` | `#FFFFFF` | primary 위 글자·아이콘 |
| `userBubble` | `#5B4BD0` | `#4F3FC4` | 내 메시지 |
| `onUserBubble` | `#FFFFFF` | `#FFFFFF` | 내 메시지 글자 |
| `star` | `#FFD27A` | `#F2B544` | 온라인 점, 안 읽은 배지, 선톡 칩 |
| `onStar` | `#2B1A0E` | `#2B1A0E` | star 위 글자 |
| `error` | `#FFB4AB` | `#A82018` | 오류 안내, 되돌릴 수 없는 동작 |
| `onError` | `#4A0F0C` | `#FFFFFF` | error 위 글자·아이콘 |

대비(WCAG 공식으로 계산): 본문/배경 다크 16.2:1·라이트 15.7:1, 내 메시지 글자 다크 6.3:1·라이트 7.4:1, 보조 글자/말풍선 다크 7.0:1·라이트 6.6:1. 오류 글자/말풍선 다크 10.0:1·라이트 7.3:1, error 위 글자 다크 9.1:1·라이트 7.3:1. 전체 값은 `tokens.json`의 `contrast`.

- `surface`와 `background`는 대비가 1.1~1.2:1이라 거의 구분되지 않는다. 캐릭터 말풍선에는 **`outline` 1dp 테두리를 반드시** 준다.
- `star`는 "별빛"이다. 온라인 점, 안 읽은 배지, 선톡 칩에만 쓴다. 버튼·배경·본문에는 쓰지 않는다.
- `error`는 오류 안내와 삭제처럼 되돌릴 수 없는 동작에만 쓴다. 밤하늘 한 가지 톤 원칙의 예외이므로 `star`와 같이 쓰는 자리를 늘리지 않는다. 장식·강조에 쓰지 않는다.
- 이미지 위 글자, 그라데이션 배경은 아이콘·스플래시 외에는 쓰지 않는다.

## 3. 타이포그래피

글꼴은 **Pretendard**(SIL OFL 1.1, 글꼴 단독 판매 외 상업적 이용 가능). 앱에 포함하기 전에 원문 라이선스를 한 번 더 확인한다.

| 요소 | 값 | 비고 |
| --- | --- | --- |
| 캐릭터 이름(상단바) | 18sp SemiBold | 상태 문구 13sp Regular |
| 메시지 본문 | 16sp Regular, lineHeight 23sp | 설정에서 14~20sp |
| 시간·읽음 | 11sp, `onSurfaceVariant` | 말풍선 바깥 아래 |
| 날짜 구분선 | 12sp Medium, 알약 칩 | 가운데 정렬 |

## 4. 간격·모서리·크기 (dp)

| 요소 | 값 |
| --- | --- |
| 화면 좌우 여백 | 16 |
| 말풍선 안쪽 여백 | 가로 14, 세로 10 |
| 같은 사람 연속 메시지 간격 / 사람이 바뀔 때 | 4 / 12 |
| 말풍선 모서리 | 20, 꼬리 쪽 모서리만 6 (연속 메시지는 꼬리 생략) |
| 말풍선 최대 너비 | 화면의 78% |
| 사진 모서리 / 최대 너비 | 16 / 240 |
| 입력창 | 최소 높이 48, 모서리 24(알약), 최대 5줄 |
| 아바타 | 상단바 40, 말풍선 32, 채팅 목록 52, 온라인 점 10 |
| 최소 터치 영역 | 48 |

## 5. 핵심 컴포넌트

**채팅 목록(홈)** — 캐릭터가 여럿이라 채팅 목록이 홈이다. 행마다 아바타 52(온라인 점), 이름, 마지막 메시지 한 줄, 시간, 안 읽은 수 배지(`star`). 선톡이 온 대화는 맨 위로.

**상단바** — 아바타 40 + 온라인 점, 이름, 캐릭터별 상황 문구(예: "지금 퇴근 중"). 스크롤하면 배경에 가벼운 블러 + 하단 구분선. 아바타 탭 → 캐릭터 프로필.

**말풍선**
- 캐릭터: 왼쪽, `surface` + `outline` 테두리, 묶음 첫 메시지에만 아바타 32.
- 나: 오른쪽, `userBubble`, 아바타 없음.
- 시간은 묶음의 마지막 메시지에만. "읽음"은 내 마지막 메시지 아래에만.
- 사진: 탭하면 전체화면, 로딩 중 스켈레톤 셔머.
- 길게 누르면 리액션 바 + 복사·다시 생성.

**입력창** — 하단에 떠 있는 알약 컨테이너. 알약 안에는 입력칸과 전송 버튼만 둔다. 글자가 있으면 전송 버튼이 `primary` 원형 48로 커지고, 비어 있으면 회색 아이콘. 응답 생성 중에는 정지(■) 버튼.

**보조 버튼 줄** — 입력과 나란히 쓰는 진입점이 둘 이상이면(사진 첨부, 행동 묘사, 미디어 생성 등) 알약 바로 위에 한 줄로 왼쪽 정렬한다. 글자 13sp `onSurfaceVariant`, 각 버튼의 터치 영역 48. 진입점이 사진 첨부 하나뿐이면 줄을 만들지 않고 알약 안 왼쪽에 `＋`를 둔다. 알약 안에 진입점을 여러 개 넣지 않는다.

**선톡** — 알림은 캐릭터 아바타 + 첫 문장(`NotificationCompat.MessagingStyle`). 앱 안에서는 새 메시지 위에 "{이름}님이 먼저 말을 걸었어요" 칩(`star`).

**캐릭터 프로필** — 큰 사진 헤더, 나이·직업·한 줄 소개, 장기 기억을 "우리의 추억" 카드로.

## 6. 모션

모두 스프링 기반, 가능하면 `MotionScheme.expressive()` 값을 쓴다. 밀리초는 출발점이며 실기기에서 조절한다. 시스템 "애니메이션 제거"가 켜져 있으면 생략한다.

| 순간 | 동작 | 길이 |
| --- | --- | --- |
| 내 메시지 전송 | 입력창 쪽에서 올라오며 scale 0.9→1 | ~250ms |
| 캐릭터 응답 대기 | 말풍선 안 점 3개가 차례로 통통 | 점마다 150ms 지연 |
| 캐릭터 메시지 도착 | 타이핑 말풍선이 메시지로 변신 | ~300ms |
| 여러 말풍선 답장 | 사이사이 타이핑 점을 다시 보이며 순차 도착 | 0.6~1.5초 |
| 리액션 | 이모지가 통 튀며 모서리에 붙음 + 가벼운 진동 | ~200ms |
| 전송 버튼 활성화 | 회색 아이콘 → `primary` 원형 | ~150ms |

## 7. 앱 아이콘

S와 Y 사이로 별똥별이 떨어지고, 배경은 보라 성운 은하다. 별똥별 꼬리가 Y 뒤에서 S 쪽으로 이어져 "어딘가에 있을 너와 나"를 잇는다.

- 글자: Pacifico(SIL OFL 1.1) 기반 S·Y를 **외곽선 도형**으로 변환. 앱에 폰트 파일은 들어가지 않는다.
- 규격: 적응형 아이콘 레이어 108×108dp, 로고는 가운데 66dp 안. 단색 레이어로 Android 13+ 테마 아이콘 지원.
- 적용: `icon/export/res/`를 앱의 `app/src/main/res/`에 덮어쓴다. Manifest에 `android:icon="@mipmap/ic_launcher"`, `android:roundIcon="@mipmap/ic_launcher_round"`.
- 원본 수정은 `icon/source/*.svg`에서 하고, 내보낸 PNG를 함께 갱신한다.

## 8. 구현 에이전트 규칙

UI를 만들거나 고치는 에이전트는 다음을 지킨다.

1. 작업 전에 이 문서와 `tokens.json`을 읽는다. 이슈에 Visual Spec이 있으면 그것도 읽는다.
2. 색·글자·간격·모서리 값은 `tokens.json`에 있는 것만 쓴다. 하드코딩한 hex/dp가 필요하면 먼저 토큰을 추가하자고 제안한다.
3. `MaterialTheme.colorScheme` 기본값, Dynamic Color, 임의의 그라데이션을 쓰지 않는다.
4. `star` 색은 온라인 점·안 읽은 배지·선톡 칩 외에는 쓰지 않는다.
5. 새 화면은 라이트/다크 스크린샷 두 장과 함께 PR에 올린다.
6. 이 문서와 Visual Spec이 충돌하면 Visual Spec이 우선이고, 기능 동작은 앱 이슈가 우선한다.
7. 단 **2026-10-12 이전 `issues/*.html`의 색·글자·치수는 기준이 아니다.** 그 시안에서는 화면 배치와 정보 계층만 기준으로 쓰고 색·글자·치수는 `tokens.json`을 쓴다. 규칙 6의 우선순위는 배치와 상태 표현에만 적용한다.
