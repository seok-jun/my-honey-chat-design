MY HONEY CHAT · ISSUE #437 · UI/UX VISUAL SPEC

관리할 상대와 대화할 상대를 분리

설정과 채팅에서 하나의 Persona 관리 화면에 접근합니다. 상세 열람·편집은 대화 상대를 바꾸지 않습니다.

합성 식별자 A / B로 화면 구조를 표현합니다. 실제 대화·프로필 데이터는 사용하지 않습니다.
이 시안은 화면 배치와 상태 표현의 기준입니다. 저장·전환·provider 동작은 실행하지 않습니다.

03 / 공통 관리 화면
‹

더보기: 외형 사진 · 복제 · 내보내기·공유 · 삭제. 삭제 확인과 마지막 Persona 제한은 유지합니다.

신규 생성 화면은 생성 뒤 대화 상대가 바뀜을 알립니다. 현재 상대 삭제 확인은 전환될 fallback을 표시합니다.

뒤로: 설정에서 왔으면 설정으로, 채팅에서 왔으면 채팅으로.

일반 전환은 명시적 선택으로. 빠른 목록에서 상대 선택 또는 관리 화면의 ‘대화하기’로 전환합니다. 기존 생성 후 자동 선택·현재 상대 삭제 후 fallback은 별도 lifecycle 예외로 유지합니다.
