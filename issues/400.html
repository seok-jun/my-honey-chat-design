취소켜기

xAI key가 필요해

대화는 xAI Grok으로만 동작해. 설정에서 xAI API key를 먼저 저장해줘.

취소설정 열기
Proposed모드 시트 없음
∅ 모드 확인 시트·모드 xAI key 안내 시트 없음 시트를 여는 칩이 없으므로 두 시트 모두 화면에 나타나지 않는다.
관련 action(켜기·취소·설정 열기)도 없다.

두 AlertDialog를 통째로 지운다

  • 「언리밋으로 바꿀까?」: 켜는 방향에만 뜨던 확인 시트. 본문 두 줄(UNLIMITED_CONFIRM_DETAILS)과 [취소] [켜기]를 함께 지운다.
  • 「xAI key가 필요해」: key 없이 칩을 탭했을 때 뜨던 안내 시트. [취소] [설정 열기]를 함께 지운다.
  • Current에서는 두 시트가 동시에 뜨지 않는다. 여기서는 비교를 위해 겹쳐 보였다.
기존 전송 차단은 그대로 xAI key 없이 대화를 보낼 수 없다는 기존 규칙과 그 화면 표현은 바꾸지 않는다. 이 Visual Spec 범위 밖이며 새 안내 UI를 만들지 않는다.

사용자 action

  • 모드를 전환하는 action은 더 이상 없다. 상단바 이름 영역을 탭해도 아무 일도 일어나지 않는다.
  • 미디어 모아보기, 더보기 메뉴, 사진 첨부, 행동 묘사, 전송 등 나머지 action과 그 이후 화면은 바뀌지 않는다.

범위 밖 — 이 Visual Spec이 바꾸지 않는 것

  • xAI key 없이 대화 전송이 막히는 기존 동작과 그 표현. 규칙은 유지되며 시각 변경이 없다.
  • 대화 수위 L4 / 미디어 수위 L3 단일 정책, 미디어 reference 통일, 미디어 턴 모델 선택, 최근 흐름 블록 전면 적용. 화면에 드러나지 않으므로 Issue 본문을 따른다.
  • 별도 콘텐츠 사용자 설정, 요금제·연령 확인 UI. 이 Issue에서 새 화면을 만들지 않는다.
Persona 이름 「페르소나」, 말풍선 「메시지 예시」는 합성 자리 표시다. 실제 대화, 사용자 데이터의 Persona 이름, prompt를 쓰지 않았다.
색 기준: feature-ui/.../ChatScreen.kt의 NormalBubble·NormalIcon·UnlimitedBubble·UnlimitedIcon, ContentModeChip, ModeSheetDialog, 테마 HoneyColors.
