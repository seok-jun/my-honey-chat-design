원본 reference 주의

FACE/BODY를 켜면 실제 이미지 파일이 패키지에 들어갑니다. BODY 원본은 FACE 원본 없이 단독으로 공유할 수 없습니다.

대화, Memory, Relationship, 현재 Mood, 생성 미디어 기록, API key/token, 모델 호출 로그, 로컬 절대 경로

가져온 외형 상태

추출 외형 텍스트가 있으면 언리밋 준비 상태로 가져올 수 있다. FACE/BODY 원본이 포함되면 노말 reference로 저장한다. 원본만 있고 추출 텍스트가 없으면 가져온 뒤 분석이 필요할 수 있다.
