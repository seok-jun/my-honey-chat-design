배치와 조작

  • 입력칸 위 보조 버튼 줄에 생성 진입점 하나를 추가합니다.
  • 종류를 선택한 뒤 생성 버튼으로 실행합니다.
  • 말풍선의 듣기는 해당 답변을 대상으로 합니다.
  • 최소 48dp 터치 영역과 화면 낭독기 이름을 제공합니다.

결과를 다루는 기준

  • 실행 시점의 캐릭터·장면 또는 답변을 고정합니다.
  • 유효한 기존 음성은 재생하고 다시 생성하지 않습니다.
  • 기존 답변·이미지·영상은 덮어쓰지 않습니다.
  • 실패 재시도는 같은 입력을 사용하고 조건을 다시 확인합니다.

시안 검토 안내

위 상태 버튼으로 완료·실패·비활성 화면을 직접 확인합니다. 메뉴의 생성 버튼은 ‘생성 중’ 배치로만 전환하며 가짜 진행률이나 자동 완료를 제공하지 않습니다.

Current는 기존 첨부·행동·입력·전송 구조의 도식이며 실제 앱 캡처가 아닙니다. 모든 대화 영역은 빈 자리 표시자입니다.
