상태·동작 기준

  • 정상: 저장된 유효 모델 이름을 표시합니다. 로컬 key 저장을 원격 인증 성공으로 표시하지 않습니다.
  • 미선택: 홈과 모델 행에서 ‘모델을 선택해 줘’를 표시합니다. 처음 설치했을 때 임의 모델을 저장하지 않습니다.
  • 종료·미지원: 기존 모델을 표시하고 다시 선택하도록 안내합니다. 해당 항목은 제품의 목록에서 비활성 상태로 남으며 지원 모델만 선택됩니다.
  • 연결 확인 필요: key 누락·잠김·읽기 실패를 단순한 ‘key 없음’으로 단정하지 않는 공통 상태 문구를 사용합니다. 실제 전송 실패 안내는 도메인 상태에 맞춰 구분합니다.
  • 저장 실패: 기존 Snackbar 위치에 안전한 안내를 표시합니다. 성공한 설정으로 화면 상태를 갱신하거나 스케줄·테마를 적용하지 않습니다. 입력란을 비우는 기존 동작은 유지하며 재입력을 안내합니다.
  • ‘내 서버’의 기존 호환 화면은 #723에서 제거합니다. #712에서는 해당 값이 direct 키로 저장되거나 재유입되지 않습니다. 회사 선택 UI는 #721에서 제공하며 이 시안에 포함하지 않습니다.

근거: 현재 SettingsPage·SettingsRows·SettingsStateHolder·SettingsScreens 구조, Foundation 토큰. 화면의 숫자·모델은 합성 상태 예시이며 사용자 대화·비밀 키는 없습니다. 기능 정책은 앱 Issue가 원본입니다.
