앱 안에서 테마 선택 초안 · 미승인

설정 홈에 화면 행을 추가하고, 화면 페이지에서 기기 설정 따름 / 라이트 / 다크 중 하나를 고른다. 이 HTML은 화면 배치, 정보 계층, 선택 상태의 기준이다. 색·글자·치수는 foundation 토큰을 쓴다.

  • 테마를 고르는 항목이 없다. 앱은 기기 다크 모드 설정만 따른다.
  • 01 설정 홈: "앱" 묶음의 대화 바로 아래에 화면 행을 둔다(왼쪽 선은 시안 표시용 강조). AI 연결은 계속 맨 아래다. 요약 줄은 현재 선택 이름이다.
  • 02 화면: 세 선택지의 단일 선택 목록. 누르는 즉시 저장하고 앱 전체에 적용한다. 저장 버튼이 없다. 적용 뒤에도 이 페이지에 머문다.
  • 처음이거나 값이 없으면 기기 설정 따름이 선택돼 있다.
  • 아래 02에서 선택지를 눌러 보면 화면 색이 바로 바뀐다. "기기 설정 따름"일 때는 위의 기기 모드 버튼을 따른다.
