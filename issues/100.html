정보 계층: Core Identity와 관계 설정이 먼저다. 외형 reference는 별도 하위 화면으로 분리해 Persona 생성 폼이 과도하게 길어지지 않게 한다. reference 기능을 켠 경우 FACE가 primary 필수 자산이고 BODY는 secondary 선택 자산이다. 사용자는 내부 상태명 대신 “노말 준비 / 언리밋 준비 / 분석 필요”만 본다. Relationship, Mood, 대화, Memory는 Persona Definition 편집 항목으로 노출하지 않는다.
