회사 연결과 역할별 모델 선택

초안 — 앱 Issue #721 구현 기준 시안, 사람 승인 전

회사 연결부터 역할 선택, 첫 전송 확인과 기존 작업 복구까지. 각 상태는 390px 기준 다크·라이트 프레임을 함께 보여 줍니다. 좁은 화면에서는 세로로 배치합니다.

읽기 기준: docs/sdd/multi-api-settings-ui/02-plan.md Visual Spec 절 · 2026-11-15. Foundation tokens.json v1.1.0을 인라인 적용했습니다. Pretendard가 기기에 없으면 시스템 글꼴을 사용합니다.

모든 ID·건수·시각·비용은 합성입니다. 실제 key·사용자 이름·대화·prompt·미디어 원본은 없습니다. 버튼은 준비된 시안 상태로만 이동하며 저장·인증·모델·복구 API를 호출하지 않습니다.

각 화면의 ‘시안 상태’ 선택기는 검토용입니다. 제품 설정 UI에는 포함하지 않습니다. 비활성 버튼 옆의 안내가 사용 불가 사유입니다.
