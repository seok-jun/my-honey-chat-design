설정 화면을 홈 + 하위 화면 구조로 재편 초안 v2 · 미승인

대상 화면: 설정(SettingsScreenContent)과 Persona 편집의 이미지 영역. 이 HTML은 화면 배치, 정보 계층, UI 상태의 구현 기준이다. 아직 다듬는 중인 초안이며 앱 설계 승인을 뜻하지 않는다.

  • 스크롤 한 장에 모든 항목이 아래 순서로 나열된다(각 행은 실제 영역 하나를 요약).
  • 분홍색 "저장" 버튼 위쪽의 토글·key·모델만 저장 버튼을 눌러야 반영된다. 나머지는 누르는 즉시 실행된다.
  • 설정 진입 시 01 설정 홈이 열린다. 각 행은 하위 화면으로 이동하고, 하위 화면의 뒤로 가기는 홈으로 돌아온다.
  • 토글·목소리·모델은 조작 즉시 저장한다. 저장 버튼은 05 AI 연결의 key 입력에만 있다.
  • key·모델·내 서버는 05 AI 연결 한 화면에만 둔다. 관리자 모드 전용 노출은 이 Issue 범위 밖이며, 나중에 홈의 AI 연결 행 하나만 가리면 되도록 맨 아래에 둔다.
  • 모델 평가 로그는 on/off 토글이 없다. 항상 켜져 있고 읽기 전용 행으로만 표시한다.
  • key 누락으로 설정이 자동으로 열릴 때는 05 AI 연결로 바로 들어간다.
  • 하루 한도 숫자는 현재 상수 그대로 표시한다. 토글은 눌러볼 수 있지만 표시용이다.
