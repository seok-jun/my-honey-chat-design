답변 이후 설정이 바뀌면 변경됐음을 표시해요. 지금 내용으로 과거 적용 내역을 다시 계산하지 않아요.

항목 편집·인지 조정·보관/삭제의 구체 화면은 후속 설계 범위예요. 이 화면을 열거나 항목을 조회하는 동작만으로 공개 상태를 바꾸지 않아요.

시안의 상태 선택과 버튼은 화면 간 이동만 보여줍니다. 네트워크·DB·모델·복구를 실행하거나 그 결과를 흉내 내지 않습니다. 위 항목과 수치는 공개 가능한 합성 표시 자료이며 실제 대화·사용량이 아닙니다.

상태가 달라도 같은 위치에서

정상 / 관련 설정 없음

경고 없음. 답변 메뉴에서 적용 내역을 열면 “관련 설정 없음” 또는 “연결된 로어북 없음”.

전송 가능 · 설정이 없다는 이유로 재시도 요구 없음

확인 중

“설정을 확인하고 있어요.” 같은 작업의 중복 확인 버튼은 비활성화. 장시간 대기는 후속 검증의 제한 정책을 따름.

이유와 진행 상태를 텍스트로 표시

일부 조회 실패

확인된 근거로 답할 수 있으면 계속. “설정 다시 확인”은 자료 조회만 수행하며 답변을 자동 재생성하지 않음.

반복 팝업 없음 · 성공하면 현재 안내 해제

책 내용이 없음

“연결된 책을 찾을 수 없어요.” 독립된 기억만 사용. 존재하지 않는 책에 끝없는 재시도 버튼을 제공하지 않음.

원래 연결 유지 · 로어북 관리로 안내

필수 근거 부족

“필요한 설정을 확인하지 못해 이번 답변을 보류했어요.” 근거를 꾸며내지 않고 요청별 재시도 또는 관리 진입 제공.

다른 대화까지 일괄 차단하지 않음

복구 안전성 미확인

“대화 데이터를 복구하고 있어요.” 기존 복구 절차에 따라 전송 제한. 목록·진행 안내는 유지.

“무시하고 계속” 없음 · 입력 초안 보존

정상적인 제외

관련 없음·중복·문맥 한도·충돌로 제외된 경우는 적용 내역에만 표시. 핵심 근거가 부족할 때만 답변 보류로 전환.

“제외됨”이 데이터 삭제를 뜻하지 않음

과거 적용 기록 없음

“이 답변의 적용 기록이 없어요.” 현재 설정을 이용해 당시 적용/제외 이유를 추정하지 않음.

정보 없음은 실패·비용 0과 구분

스냅샷 연결 예외

다른 책·연결 미상은 교체 전 차단. 같은 책 소실은 기존 미리보기에 제한을 표시한 뒤 복원 선택.

안내·내역 범위 확정 · 복원 화면 전체 배치는 별도 설계

동작과 노출의 경계

  • 정상 답변마다 로어 상태 칩을 늘리지 않음. 오류 안내는 캐릭터 말풍선과 분리된 앱 UI이며 모델 입력·알림 본문으로 보내지 않음.
  • 적용 내역은 요청 당시 실제 제공 목록과 선택 후보의 사유 코드를 사용. 전체 책을 검사했다고 표시하거나 모델 내부 추론을 노출하지 않음.
  • 미인지 비밀은 이름·별칭·개수·제외 사유로도 암시하지 않음. 작성자용 화면은 명시적으로 이동해야 하며 열람이 인지 획득을 만들지 않음.
  • 재조회는 기존 답변을 바꾸지 않음. 재생성이 필요하면 기존 재생성 액션으로 명시적으로 실행하며 호출/비용이 생길 수 있음을 알려야 함.
  • 책 소실과 일시적 조회 실패를 구분. 재시도는 같은 작업을 중복 접수하지 않으며 계속 실패하면 해당 안내를 유지.
  • 공개 화면과 개발 로그는 다름. 개발 산출물에 실제 대화·로어·비밀·모델 내부 추론을 기록하지 않음.
